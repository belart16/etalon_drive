# Сайт «ЭТАЛОН ДРАЙВ»

Статический одностраничный сайт: HTML + CSS + JS, без сборки и без CMS.
Просмотр на компьютере — открыть `index.html` в браузере.

## Структура

```
index.html            — сайт
404.html              — страница «не найдено» (пути от корня: /assets/...)
policy.html           — политика обработки персональных данных (реквизиты заполнены)
consent.html          — согласие на обработку ПДн (отдельный документ — требование с 01.09.2025)
robots.txt            — правила для поисковых роботов
sitemap.xml           — карта сайта
site.webmanifest      — иконки для телефонов / «добавить на экран»
favicon.ico           — иконка вкладки для старых браузеров
.htaccess             — настройки Apache: 404, сжатие, кэш, закрытие служебных файлов
.nojekyll             — нужен только для GitHub Pages
assets/css/style.css  — стили (цвета — в начале файла, блок :root)
assets/js/main.js     — скрипты + НАСТРОЙКИ (SITE_CONFIG в начале файла)
assets/fonts/         — шрифт Manrope (локально)
assets/img/           — изображения (WebP + уменьшенные копии *-480/-640/... для телефонов),
                        иконки, og-image.jpg (превью для соцсетей и мессенджеров)
```

## Домен

Основной домен — **etalondrive.ru** (прописан в canonical, Open Graph, микроразметке, `robots.txt`,
`sitemap.xml`, политике и согласии). Второй домен **etalon-drive.ru** перенаправляется на основной
(301) — настройкой в панели хостинга или блоком в `.htaccess`.

## Публикация на хостинге nic.ru

1. В кабинете nic.ru заказать хостинг (с PHP — пригодится для формы) и привязать к нему домен.
2. Через файловый менеджер или FTP загрузить в корневую папку сайта всё, **кроме** `.git`, `README.md`, `.nojekyll`.
3. Включить бесплатный SSL-сертификат (Let's Encrypt).
4. После того как сайт открывается по `https://` — в `.htaccess` раскомментировать блок «Перенаправления» (http→https, www→без www).
5. Добавить сайт в Яндекс Вебмастер и Google Search Console, отправить `sitemap.xml`.

## Обновление стилей и скриптов

CSS и JS подключены с номером версии: `style.css?v=7`, `main.js?v=6`.
Браузеры кэшируют их на год, поэтому **после изменения файла увеличьте номер** в `index.html`
(и в `404.html`, `policy.html` для CSS) — иначе посетители увидят старую версию.

## Обратная связь

**Сейчас (этап 1).** Посетитель заполняет форму и жмёт «Отправить заявку» — открывается окно
«Как отправить заявку?» (на телефоне — во весь экран):
- **Gmail, Яндекс Почта, Mail.ru, Outlook** — открывается веб-почта с готовым письмом на mail@npoeta.ru;
- **Почтовая программа** (mailto) — для тех, у кого настроен Outlook/Apple Mail;
- **Скопировать текст заявки**.

Сайт данные не принимает и не хранит — письмо отправляет сам посетитель.

**На будущее (уже в коде, выключено).** В `assets/js/main.js`:
- `messengersInForm: true` + заполнить `messengers` (Telegram, WhatsApp, MAX) — кнопки мессенджеров компании в окне;
- `shareInForm: true` — системное меню «Поделиться» на телефонах.
При включении — дополнить политику и согласие (сейчас в них описана только отправка по почте).

**Этап 2.** Отправка напрямую (PHP-скрипт на хостинге → письмо): `formEndpoint` в `main.js` + файл обработчика.
Перед этим — утвердить политику конфиденциальности и проверить уведомление Роскомнадзора.

## Аналитика (Яндекс Метрика)

В `main.js` указать `metrikaId`. Цели отправляются автоматически:
`lead_prepare` (заполнил форму), `lead_channel` (выбрал способ отправки, параметр channel),
`phone_click`, `email_click`, `cfg_request`, `form_submit` (этап 2).
